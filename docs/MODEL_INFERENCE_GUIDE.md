## REST API Inference

### Single-horizon forecast

```
GET /api/v1/forecasts/{city}?model={model_id}&horizon={hours}&pollutant=PM2.5
```

Example:
```bash
curl "http://localhost:8000/api/v1/forecasts/delhi?model=stcnn_gru&horizon=24&pollutant=PM2.5"
```

Supported horizons: `1, 6, 12, 24, 48, 72`

### Model comparison table

```
GET /api/v1/evaluation/benchmark/all
```

Returns all 42 (model × horizon) rows from `master_model_comparison.csv`.

### Transfer learning results

```
GET /api/v1/evaluation/transfer/mumbai
GET /api/v1/evaluation/transfer/vijayawada
```

## Python SDK Inference

```python
import sys
sys.path.insert(0, '.')  # from ML_air root

import torch
from aerosense_ml.models.stcnn_gru import STCNNGRUNetwork

ckpt = torch.load('backend/artifacts/models/stcnn_gru_delhi.pt', map_location='cpu')
cfg = ckpt['config']
model = STCNNGRUNetwork(
    input_size=cfg['input_size'],          # 57
    cnn_channels=cfg['cnn_channels'],      # 64
    gru_hidden=cfg['gru_hidden'],          # 128
    gru_layers=cfg['gru_layers'],          # 2
    n_stations=cfg.get('n_stations', 12),
    horizons=cfg['horizons'],              # [1,6,12,24,48,72]
    dropout=cfg.get('dropout', 0.2),
)
model.load_state_dict(ckpt['network_state'])
model.eval()

# X: (batch, seq_len=24, n_stations=12, input_size=57)
# y_pred: (batch, n_horizons=6, n_stations=12)
with torch.no_grad():
    y_pred = model(X)
```

For XGBoost / Random Forest (tabular):
```python
import pickle

with open('backend/artifacts/models/xgboost_delhi.pkl', 'rb') as f:

y_pred = xgb_model.predict(X_flat)
```

## Input Feature Schema

57 features per station per timestep. See `backend/data/features/delhi/feature_columns.json` (generated by the Colab pipeline).

Key groups:
- **PM2.5 lags**: t-1, t-2, t-3, t-6, t-12, t-24, t-48, t-72
- **Meteorological**: temperature, humidity, wind speed/direction, pressure, dew point
- **Temporal encodings**: hour sin/cos, day-of-week sin/cos, month sin/cos
- **Cross-station aggregates**: network mean, std, max (12-station)
- **Rolling statistics**: 3h, 6h, 12h, 24h rolling mean and std

## Scaling

All features are standardized using `StandardScaler` fit **only** on the training split (chronological 70%). Scaler artifacts are in `backend/data/features/delhi/scaler.pkl`.

**Never** refit the scaler on validation or test data.
